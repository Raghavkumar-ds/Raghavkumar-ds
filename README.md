# 👩‍💻 About Me

I am *Raghav Kumar*, a passionate Data Analyst who loves transforming raw data into meaningful insights that support smarter business decisions.

I specialize in:
- Turning complex datasets into clear, actionable dashboards  
- Building analytical solutions for business, HR, and sales use cases  
- Identifying trends, patterns, and KPIs using Power BI, Excel, SQL & Python  
- Communicating insights through powerful visualization and storytelling  

What drives me most is *problem-solving* — understanding business challenges and using data to answer the “why” behind them.

I enjoy:
- 📊 Building dashboards that simplify decision-making  
- 🔍 Finding hidden patterns in data  
- 🤝 Collaborating with stakeholders  
- 🚀 Continuously learning & exploring new tools  

I believe *data is not just numbers — it's a language*, and I love translating it into insights that create real impact.
